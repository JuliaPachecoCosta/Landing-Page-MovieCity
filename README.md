## 🎟️ SINOPSE DO PROJETO

Imagine entrar em um cinema e ter vários filmes esperando por você.

O **MovieCity** é um catálogo de filmes desenvolvido com React, JavaScript, Vite e CSS3. Inspirado na experiência das plataformas de streaming, o projeto apresenta uma interface escura, detalhes em vermelho e cards visuais para explorar diferentes títulos.

Mais do que uma página, o MovieCity é um projeto de aprendizado que reúne design, organização de componentes e desenvolvimento front-end.

## 🍿 O QUE ESTÁ EM CARTAZ?

### 🎞️ Funcionalidades implementadas

- 🎬 Catálogo visual com seis cards de filmes e séries.
- 🖼️ Imagens de fundo para os títulos.
- ⭐ Exibição de títulos, gêneros e avaliações ilustrativas.
- 🧩 Componentes reutilizáveis com React.
- 📱 Layout responsivo para computadores, tablets e celulares.
- 🍿 Menu adaptado para telas menores.
- 🎨 Identidade visual inspirada no cinema, com preto e vermelho.
- 🔄 Renderização dinâmica dos cards com `.map()`.
- ⌨️ Melhorias de navegação por teclado e foco visível.

## 🎟️ COMO ENTRAR NA SALA?

### Pré-requisitos

- Node.js compatível com a versão do Vite utilizada.
- npm.
- Visual Studio Code ou outro editor de código.

### 1. Clone o repositório

```bash
git clone URL_DO_SEU_REPOSITORIO
```

### 2. Entre na pasta do projeto

```bash
cd 01_landinpage
```

### 3. Instale os pacotes

```bash
npm install
```

### 4. Acenda o projetor!

```bash
npm run dev
```

### 5. Entre no MovieCity

Acesse o endereço apresentado no terminal, normalmente:

```text
http://localhost:5173
```

Se o Vite indicar outra porta, utilize o endereço exibido.

## 🎬 CRÍTICA TÉCNICA

Antes da estreia, verifique se o código está funcionando corretamente.

**Verificação do código:**

```bash
npm run lint
```

**Compilação para produção:**

```bash
npm run build
```

Teste também o layout em diferentes larguras de tela e confira se as imagens, o menu e os cards são exibidos corretamente.
